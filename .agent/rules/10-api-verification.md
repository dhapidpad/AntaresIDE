# Upstream API verification

- Inspect the checked-out Lapce and pinned Floem source before using APIs.
- Inspect the pinned Octomind release docs/source before using ACP or MCP fields.
- Do not copy examples from a different version.
- Record version, revision, source path, and compatibility assumptions in docs.
- Prefer existing Lapce subsystems instead of recreating them.
- Keep Octomind external; do not vendor its entire repository.
