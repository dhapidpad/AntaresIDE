# Core rules

- Read `AGENTS.md`, `docs/STATUS.md`, and the active roadmap phase first.
- Use Gemini 3.8 Flash in Antigravity for implementation; keep coding model choice separate from the in-app Octomind provider.
- State a <=10-line plan, inspect exact source, implement one vertical slice, run tests, and report exact evidence.
- Never fabricate protocol fields, provider IDs, API results, test outcomes, or feature completion.
- Keep one task/branch/commit focused. Use `agy/<phase>-<topic>`.
- Stop and record a blocker after five root-cause attempts, not five random edits.
