# How to contribute

Thank you for your interest in contributing to Antares IDE! No contribution is too small and we consider _all_ contributions to the project. There are many ways to contribute (a few are listed here) but if you think of something else, let us know via an [issue](https://github.com/dhapidpad/AntaresIDE/issues).

## Questions

If you have questions or ideas, you can open a [Discussion](https://github.com/dhapidpad/AntaresIDE/discussions) or submit an [issue](https://github.com/dhapidpad/AntaresIDE/issues).

## Feature Requests

A feature request is _editor behaviour or agent integration that you want to have included in Antares IDE_. We track feature requests on GitHub via [issues](https://github.com/dhapidpad/AntaresIDE/issues). There are generally a few kinds of features:

### Core editor & AI integration features

Features relating to core editor capabilities or AI agent workflows. Please make a suggestion in an [issue](https://github.com/dhapidpad/AntaresIDE/issues).

### Programming language support (autocompletion/intellisense/formatting)

Features that relate to specific programming language support, language servers (LSP), or developer tools.

---

To reduce duplicate requests, please search through existing issues first.

## Bug Reports

Bugs should be reported on GitHub via [issues](https://github.com/dhapidpad/AntaresIDE/issues). This allows us to track them and reproduce them systematically.

## Pull Requests

If you want to contribute code or documentation:
1. Fork and create a topic branch (`agy/<feature-name>`).
2. Run `cargo fmt -p antares-agent` and `cargo clippy -p antares-agent --all-targets -- -D warnings` to verify code quality.
3. Open a Pull Request on [Antares IDE](https://github.com/dhapidpad/AntaresIDE/pulls).
